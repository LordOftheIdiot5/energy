# Atlas runtime resource budget
Do not preload optional infrastructure archives at homepage load or when Atlas opens with layers off. Browser regression enforces zero optional dataset requests until selection and one request per selected dataset within a page session. Record response lengths where available; not a full network performance benchmark. Reuse filtered rows and dropdown options when unchanged, debounce text search 150ms, cap fallback SVG reprojection at 10 Hz during movement and skip unchanged camera. GPU feature enumeration on idle after initial readiness, not every frame. Keep final camera paint, existing source filtering and fallback. Future: versioned lightweight identity indexes and vector water tiles, on-demand country partitioning, memory/CPU profiling on real devices, and CDN range budgets. No claim of measured CPU savings before benchmarks.
