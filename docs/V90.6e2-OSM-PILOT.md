# Regional data-centre acquisition pilot
Iceland and Luxembourg selected for manageable public Geofabrik extracts; not a coverage priority ranking. https://download.geofabrik.de/europe/iceland.html and https://download.geofabrik.de/europe/luxembourg.html. Explicit tags per https://wiki.openstreetmap.org/wiki/Tag:telecom%3Ddata_center. Only named public records, no contact/security/operational attributes. Preserve source object identity, source hash, retrieval time, ODbL attribution and point-vs-area distinction. Area representative points are approximations. Do not infer spare capacity, network connectivity or operational status. ODbL data file remains separate from WRI and proprietary databases; publish separate licensed downloads and attribution before map integration. CI collects a bounded source artifact only; no production commit/deployment and no completeness claims. National coverage expansion after real extraction validation and data/storage review.
