# V90.6g4b — mixed Atlas stress, Pacific longitude and EIA source cache

Status: **implementation and automated acceptance under GitHub CI; do not infer production success until post-deploy smoke runs**.

## Measured risks identified in the existing code

The public Energy Atlas independently loads four source-dated infrastructure
cohorts on opt-in: UK DESNZ REPD October 2026 mapped projects (14,388);
US EIA-860M September 2026 generator units (40,048 across four **mutually
exclusive inventory categories**, with 28,712 in the "operating" inventory);
NACEI August 2017 facility reference (1,461 across three categories);
and GEM November 2025 gas transmission pipelines (4,246 source records,
3,921 simplified route geometries).

Two implementation issues are independently testable without new data:

- The US inventory bounds routine deliberately discarded all longitudes
  greater than zero. That is not valid for published US territory records
  and prevents a source-native selected point in the Western Pacific from
  being fitted to the map when present. A minimal circular longitude
  interval now supports positive coordinates and exact dateline crossing,
  for example +179° / -179° fits as [179°,181°], not 358°.
  When showing the entire diverse US source inventory, the current
  documented continental default view is retained; filters and exact
  source records can still navigate outside that view.
- The US generator source partition loader retained fulfilled promises for
  every visited inventory category in addition to validated JSON objects.
  A bounded **two-inventory** in-memory LRU cache and explicit completion
  cleanup prevent indefinite accumulation of all four partitions. The
  active inventory remains accessible, and revisiting a recently used
  inventory reuses the validated session data. Older evicted partitions
  may be refetched, never silently recomputed or published.

## Acceptance and instrumented browser baseline

Use the existing reviewed source fixtures and the actual allowlisted Pages
artifact at **1440, 1024 and 390 CSS px**. The test:

1. Confirms heavy source files remain opt-in and licensed source counts,
   source statuses and existing inspector semantics are unchanged.
2. Enables the UK, NACEI gas, GEM pipeline and US operating-inventory
   overlays simultaneously; checks the approved row counts, route layer,
   bounded on-screen marker groups and retention of all four toggles.
3. Jumps through UK, Norway, US, worldwide and both sides of **180°**
   longitude; confirms source rows remain available and the relevant
   UK/US/NACEI symbols reappear in their own geographic views.
4. If the reviewed 40,048-row original EIA source includes an actual
   positive-longitude record, selects that exact source ID and checks
   "View US" navigates to its positive-longitude bounds. Independently
   tests synthetic ±179° and Pacific geography as a pure coordinate
   algorithm — **no invented public map features**.
5. Exercises four original EIA inventory categories and asserts the
   validated in-memory cache retains at most two categories and no
   completed request promises. Tests the original EIA browser/inspector
   workflow and UK coexistence.
6. Logs **actual Chromium V8 heap use** using the DevTools Runtime
   protocol at first load, under mixed layers and after inventory
   switches; also logs source response Content-Length values if
   provided. These are CI-specific **telemetry**, not GPU texture
   allocation, total browser-process memory, transfer-compressed bytes,
   or a memory performance promise.
7. Protects responsive horizontal overflow, missing approved source
   files, unexpectedly repeated source requests, and uncaught page
   exceptions. No unrelated source is disabled when another layer is
   toggled.

## Explicit limitations

This increment does not add a generalized world dateline topology solver
for long route geometries, nor does it change GIS source locations or their
rights. No engineering/survey accuracy or current operational status is
inferred. Interactive data sources remain source-dated. Longer-run memory
leak tests, GPU/CPU frame traces on physical mobile devices, all-layer
aggregation under 100,000+ source objects, ancient PR #70 rebase and
vector-tile budgets remain follow-up work. Cloudflare private R2/D1
provisioning and the official newer GEM LNG source remain gated separately.
