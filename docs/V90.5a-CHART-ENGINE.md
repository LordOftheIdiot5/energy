# V90.5a chart engine first increment
Shared chart renderer for overview prices, weekly reservoir history and Nordic observed data. Range selection by recorded timestamp index, presets relative to latest available observation (not a claim of complete period), reset, UTC readout, keyboard inspection, exact delivery intervals including last interval, gap-aware line segments, table preview. Visible CSV only with explicit source attribution/licence on open observation datasets. No new bulk price export. Existing full selected series export/table retained. Cross-chart synchronization, brush navigator, annotations and multi-dataset comparisons remain later increments. No existing data feed changed.
