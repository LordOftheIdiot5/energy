# V90.1 publication barrier — 18 November 2026
The energy repository is public. The mixed energy.json is accessible both through the production site and the GitHub repository; historical Git commits must also be considered. Removing a download link does not establish redistribution compliance.
The new projection is an isolated candidate for deployment, not authorization or an active production gate. It does not change source data. It excludes Yahoo quotes and dependent margins/correlations/FX, unverified Nordic reseller prices, GB index and other unreviewed mixed fields. EIA public-domain Brent/WTI spot observations are retained with attribution. The selected ENTSO-E categories remain geographically scoped. Elexon BMRS data licence: https://www.elexon.co.uk/bsc/data/balancing-mechanism-reporting-agent/copyright-licence-bmrs-data/ — separate third-party exceptions and FX must be checked before restoring the GB index. EIA: https://www.eia.gov/about/copyrights_reuse.php.
Release gates:
- Move collection of any non-public or restricted source data out of the public repository; retain private data only where the source terms permit. Review existing history and public copies with the repository owner.
- Deploy ONLY an explicitly allowlisted static artifact. Never upload the full repository or unchecked archive partitions. Keep cleared historical observations in a durable independent source store.
- Integrate approved prices in the visual chart, use EIA spot references (not futures), implement official-source cards for blocked datasets, and verify every affected renderer with the projected data.
- Review and clear additional assets, map hosting, benchmark files, project news and source-derived content independently.
- Run full static archive validation, desktop/mobile visual tests, public URL smoke checks and a data-leak audit. No release advance to V91 or claim of full commercial readiness before these gates pass.
