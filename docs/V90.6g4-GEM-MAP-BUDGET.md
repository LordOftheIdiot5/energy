# V90.6g4 — GEM transmission-pipeline map interaction budget

Status: **staged improvement and CI measurement; not a claim of measured production CPU savings until the browser gates pass**.

## Scope

The licensed and source-pinned GEM **November 2025** gas-transmission pipeline
layer contains 4,246 source records, including 3,921 simplified source routes and
325 records with no mapped route. The map intentionally loads this layer **only**
when the user enables it, with status reflecting the 2025 tracker rather than
current independently verified operations.

Earlier UI code built a MapLibre source filter by enumerating up to thousands
of pipeline IDs every time status, country or text changed. Even though geometry
stayed in the same GeoJSON source, these long expressions were repeatedly sent
to the map style engine, including on every search keystroke.

## Change and verifiable invariants

- Status changes use a compact equality expression on the existing
  source-reported status property (not thousands of matching IDs).
- Country changes use two explicit endpoint-country equality checks, preserving
  the existing source-native search semantics. Country is an endpoint match,
  not guessed from route geometry.
- Only free-text searches, which match source catalog names, IDs and places,
  require an exact list of matching pipeline IDs; those strings are not
  artificially embedded into all source-line properties.
- MapLibre filter assignments are skipped when the status/country/search
  signature has not changed. Rapid free-text edits coalesce through a bounded
  **150 ms** browser timer, while directory results, record counts and inspector
  selection remain immediate.
- Timers and filter signatures are cleared when the map instance changes, to
  prevent stale search results from modifying a replacement map. Disabling and
  re-enabling the layer retains the original source data within the session.
- The CC BY 4.0 provenance, source statuses, search for all 325 unmapped
  records, source inspector, disabled-layer behavior, NACEI coexistence and
  fallback map behavior are unchanged. No new geometry or current operation
  asserted.

## Measurements and acceptance

The PR test suite measures the ratio of source expression sizes for the exact
reviewed 2025 data and emits **observed** browser timings rather than promising
guaranteed frame rate or energy savings. It tests at 1440, 1024 and 390 CSS px:

1. No GEM file requests before the source layer is enabled; once enabled,
   the catalog and route archive are each fetched once and retained across
   a layer toggle.
2. Exact approved source records (4,246), routes (3,921), original statuses,
   status and endpoint-country filters, full native-ID search and source links.
3. Compact status/country filter expressions; at most one MapLibre filter
   application for a burst of rapid search edits.
4. Two scripted camera changes, no disappearing source count, no horizontal
   overflow, no page errors, independent historical NACEI overlay.
5. Existing GEM browser checks, pinned-source Python rights/publication
   tests and rights-allowlisted public-site artifact.

The new measurements are CI-specific telemetry for regression triage, **not**
mobile-device CPU/GPU memory profiling or a broadband SLA. Broader atlas
tile-budget, dateline, mixed UK/US generators, country-region splits and old
PR #70 resource changes still require their own review before merging.

**No Cloudflare R2/D1 data history activation is part of this map optimization.**
