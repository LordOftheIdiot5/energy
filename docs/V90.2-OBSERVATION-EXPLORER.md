# V90.2 observation explorer
Dedicated hourly GitHub Actions collection commits only HydAPI and Fingrid observation paths, avoiding conflicts with other energy snapshot files. The existing full fetch skips the new provider collector in Actions; the VPS should not use Nordic credentials unless acting as the sole writer. HydAPI requests are bounded by station and supported parameter; stage/discharge/temperature daily observations retain quality flags. The station map does not identify hydrological stations as plants. Finland country dashboard uses measured MW and only compares aligned intervals. The published observation index lists available JSON archives and hashes. No existing source or feature is removed. Wider historical backfill and exact plant-catchment joins remain follow-up work.
