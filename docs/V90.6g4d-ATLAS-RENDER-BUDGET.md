## Intended source-preserving changes

- **Opt-in WRI 2021 historical GPU/vector mode:** MapLibre's full-viewport `queryRenderedFeatures({layers})` previously ran on every `render` event **and** every `idle` event. With MapLibre's busy 60fps camera/animation events this can repeatedly enumerate the same large feature population. Keep `render` calls until the original PMTiles source first shows actual features (readiness/fallback remain intact), then enumerate features on settled `idle` only. Retain pointer-specific feature query on user hover/click and failover to standard viewport symbols. Export non-sensitive diagnostic counters for scan calls and wall-clock durations (JavaScript time, not GPU kernel time).
- **Natural Earth 5.1.2 fallback:** Reprojection traverses every polygon/ring point. Throttle camera `move` reprojection at 10Hz and skip identical viewport/camera signatures; ensure `moveend` still triggers a final paint. Never invent coastlines or replace the reviewed data. Count real path paints to detect duplicate work.
- **WRI source filters:** Reuse the filtered 2021 source rows and first 200 directory choices when the source, on/off state and all four filter controls are unchanged; invalidate automatically on changes. Preserve immediate text-search semantics; do not apply the old PR's 150ms search delay because some existing inspector/browser interactions expect immediate results.
- **Mixed layers:** Local minimalist world basemap does not obscure the separate regional electrical-network option when that layer is active. Existing NACEI/GEM/EIA/UK source logic and the independent default/non-GPU renderer are unchanged. The two modified scripts are URL-versioned in `index.html` for cache coherency.

## Actual browser acceptance, not assumptions

Build **only** the rights-approved Pages artifact and stage the content-addressed WRI PMTiles from its exact pinned source, retaining the correct range/sha validation. Chromium at 1440/1024/390 CSS px must:

1. Prove zero optional heavy source requests on the homepage and opening the Atlas with all data layers disabled; loading WRI cannot fetch unrelated GDW/ODbL sources.
2. Check source counts and opt-in WRI archive one-request/session reuse across toggles.
3. Verify real SVG coordinates and full coastlines at the world view. Send 60 redundant same-camera move notifications: no extra Natural Earth paths. After a real camera change the path must update, without refiltering all historical WRI rows.
4. Search an original source asset and ensure the source-filter counter increases for a real change.
5. Load the genuine staged PMTiles source with HTTP 206 ranged responses, show GPU symbols, force 30 MapLibre render frames, and measure **actual full-viewport feature-scan call counts** before and after. A successful optimization must measurably avoid one scan per render frame while still recomputing after a real camera move.
6. Record V8 heap, source requests, PMTiles range bytes and errors. These are runner-specific measurements and are **not** total device RAM, GPU VRAM, real-world transfer bandwidth or guaranteed mobile FPS.
7. Verify fallback after GPU opt-out, source inspector and asset search and no page errors/viewport overflow; run existing full global map, GPU inspector/fallback and GDW browser regression suites.

The benchmark intentionally reports **observed JavaScript full-viewport feature scans**, not graphics draw calls, measured GPU time, FPS, real user bandwidth or a before/after hardware speedup.
