# Regional electrical network coverage expansion
Pilot Estonia, Latvia, Faroe Islands and Albania. Geofabrik's public regional directory (https://download.geofabrik.de/europe.html) lists their PBF extracts within the existing 150,000,000-byte cap at review time. Extracts can grow; fail closed on size, transport or data failure. Four independent jobs, no production archive modifications, separate ODbL attribution and source identity per cohort. Existing Iceland/Luxembourg publication and weekly refresh keep their original required region set. New cohorts require successful source counts, review, archive admission, dynamic map catalogue and visual validation before public display. Norway, Sweden, Denmark and Finland require separately budgeted larger-extract infrastructure; do not silently raise current cap. No engineering accuracy, network topology or live operation claimed.
