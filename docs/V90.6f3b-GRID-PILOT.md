# Regional public grid mapping pilot
First two manageable extracts: Iceland and Luxembourg, aligned with our digital pilot. Generalized public map lines and substation representative points, separate ODbL cohort with source path, SHA-256, retrieval time, explicit classifications and missing values. Do not infer electrical network topology, circuit capacity or live loads; exclude internal busbars/bays and detailed security/access fields. Underwater includes inland water and is not automatically submarine. No public release yet.
Sources: https://wiki.openstreetmap.org/wiki/Tag:power%3Dline ; https://wiki.openstreetmap.org/wiki/Tag:power%3Dcable ; https://wiki.openstreetmap.org/wiki/Tag:power%3Dsubstation ; https://www.openstreetmap.org/copyright ; https://download.geofabrik.de/europe.html .
Acceptance: live extraction with source-count accounting; ordinary ODbL separate publication, line/point styling and voltage filters, click-to-inspect using source identities and broader click tolerance, actual screenshots and GPU line rendering tests before deployment. Existing NVE public rendered overlay must retain source restrictions and remain independent. Geofabrik had recent connectivity failures; no invented records or fallback to unauthorized services.
